# UI Guidelines

## Purpose

This document defines RegIntel's design language, component conventions, and UX principles so the interface stays consistent as the product grows. The target design language draws inspiration from Apple, Linear, and Harvey AI (see [`CLAUDE.md`](../CLAUDE.md)), but concrete tokens and rules are not yet defined.
